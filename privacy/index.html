1. Scope and operator

PaceLoop is an independent developer project maintained by LeeDeokho, the owner of the linked GitHub repository, not an incorporated company. This policy covers this public informational website, the current local single-user PaceLoop prototype, the browser workspace at paceloop.emeralho.workers.dev, and messages sent to our support address. Privacy contact: support.ducklab@gmail.com. A hosted multi-user service and mobile apps have not launched.

2. Informational website on GitHub Pages

The separate informational site at leedeokho.github.io/paceloop-site is hosted by GitHub Pages. It has no account registration, Garmin sign-in, health-data upload form, advertising, analytics scripts, or application cookies added by PaceLoop. Visiting that informational site does not connect your Garmin account or send your local training records to us. GitHub may process technical request information, including IP addresses and request logs, to operate and secure its hosting. See the GitHub Privacy Statement. The Cloudflare workspace has different processing as described below; this policy is available on both sites.

Browser workspace on Cloudflare

Garmin Personal API (personal testing): You may enter your own Personal API key to retrieve the most recent 91 days of activity and available sleep, HRV and resting heart-rate summaries. With “Remember key in this browser” selected, the key is encrypted with AES-GCM in IndexedDB after a successful sync and reused on later visits. Its non-exportable decryption key is stored in the same browser, so anyone or any site script with access to this browser profile can still use the connection. You may deselect this option to keep the key only in the current tab memory. Keys are excluded from backups. The Cloudflare relay temporarily processes the key, a Garmin access token and responses in request memory without persisting or logging them. Only fixed, read-only Garmin endpoints are available. Original FIT files for charts pass through relay memory and are parsed in the browser; neither the original files nor GPS coordinates are retained by PaceLoop. Selected measurements and a one-way account identifier remain in this browser. Disconnecting the personal key clears it from memory and browser storage and leaves imported records; revoke the key in Garmin Connect to prevent all use. This is a personal testing connection, not approval for a commercial multi-user integration.

The public browser workspace stores imported activity measurements, goals, profiles, plans, recommendation context and estimated API usage in IndexedDB in your browser profile. It does not upload your existing local database. Another browser starts empty; people sharing the same browser profile share its stored data. Clearing site data or closing a private browsing session may erase these records. JSON backups include stored activities, selected samples and laps, recovery measurements, goals, profiles, plans, API usage estimates and budget limits, plus one-way Garmin account identifiers to prevent account mixing. Credentials, OAuth sessions, original FIT files and GPS coordinates are excluded. Restore is processed in the browser and preserves existing items; imported plans require review as drafts. Backup files contain personal health information and should be kept securely. Keep original FIT files separately.

FIT and ZIP files you select are parsed in your browser. We retain selected activity and lap measurements, not original files or GPS route coordinates. Garmin automatic connection receives new activity and selected health summaries after consent, as described below.

When you select Remember key, AI API keys are encrypted with AES-GCM in IndexedDB and reused on later visits. The non-exportable decryption key stays in the same browser profile; this does not prevent access by people or scripts with access to that profile. Otherwise keys remain in the current tab memory. Keys are never included in backups. Disconnecting removes the local connection, not the provider's key itself. When you check a key, it is forwarded to that provider to list models. When you request a recommendation, your key, recent activity summaries, goals and conversation are sent through a Cloudflare Worker to the AI provider you select: OpenAI, Anthropic or Google. The relay does not persist or log request bodies, keys or responses; OpenAI Responses requests use store:false. This does not override the AI provider's own retention or processing policies. Original FIT files and route coordinates are not sent to the AI.

Cloudflare serves this workspace and processes network requests. The relay uses a hash of the connecting IP for short-lived request rate limiting. Cloudflare may process technical information for hosting and security under its privacy policy. The encrypted Garmin delivery database described below holds only temporary connection and pending-delivery data. Cross-device backup is not provided. Close or refresh the tab to discard unremembered AI and Garmin keys. Use AI connection management to delete remembered AI keys. Disconnect the personal Garmin key to remove a remembered key; clear this site's browser data and your own exports to remove stored workspace data.

Garmin automatic connection: temporary server storage

After explicit consent, Garmin sends new activity and selected health summaries to our Cloudflare Worker. We keep only the identifiers and measurements needed to display activities and recovery (date, sport, distance, time, pace, heart rate, elevation, sleep duration, HRV and resting heart rate). GPS coordinates, raw notification bodies and original FIT files are not stored on the server. Starter access does not fetch records from before connection.

Cloudflare D1 temporarily holds AES-GCM encrypted pending records for up to seven days. They are removed from the active database after the browser confirms successful IndexedDB storage. Tokens are encrypted, while an HttpOnly cookie authenticates the browser connection. Tokens are kept while connected, with automatic suspension and revocation after 30 days without access. Disconnecting immediately stops receipt and deletes pending data; failed Garmin revocation may retain credentials for up to 24 hours of retries. Cleanup runs hourly. Cloudflare recovery copies can retain earlier encrypted database states for up to 30 days; deletion does not promise forensic erasure.

One Garmin account connects to one browser profile. This is not cross-device backup. Disconnect before clearing site data, or revoke PaceLoop in Garmin Connect: clearing browser data alone does not stop Garmin sending notifications. Downloaded records remain locally after disconnect. Clear site data to remove local copies; keep exported files under your control. Correct source records in Garmin Connect and goals/plans in PaceLoop. Contact support for help accessing or deleting pending server data.

AI connection availability

The public website currently supports API-key connections only. It does not connect to a program on your computer or accept AI subscription credentials. Hosted subscription sign-in is not yet available. The former optional PC companion is no longer distributed or connected by this website. If you previously used it, its local login information remains on that computer until you log out or remove its settings; this website update does not delete it.

AI Transparency Statement for Garmin data

AI analysis is optional. Each recommendation containing automatically received Garmin data requires separate explicit consent. Selected OpenAI, Anthropic or Google services receive recent activity summaries, available recovery metrics, goals and the entered conversation through Cloudflare for API-key requests. Garmin credentials, original FIT files and GPS are never included. Recommendations are drafts for review, not medical assessments or automatic workout publications.

Garmin data and derived data must not be used to train, evaluate or improve AI models. Use only products and account settings excluding these uses; do not use a Google unpaid API tier or opt into voluntary data sharing for model improvement. PaceLoop does not train, evaluate or improve models using these records. Provider retention for processing, security and legal obligations is separate. Uncheck consent, stop further recommendation requests, or disconnect the AI key to withdraw future processing consent. This does not erase requests already sent; deletion of provider-held copies must be requested from that provider. We do not sell Garmin data or share it for advertising.

Garmin 자동 연결과 임시 보관: Cloudflare가 새 운동·건강 알림을 받고 GPS와 불필요한 필드를 제외합니다. 인증 정보와 미전달 기록은 D1에 암호화합니다. 기록은 최대 7일 보관하며 브라우저 저장 확인 후 운영 DB에서 바로 삭제합니다. 연결 해제 또는 30일 미접속 시 수신을 중단하고 철회하며, 철회 오류는 최대 24시간 재시도합니다. 정기 정리는 매시간 실행하고 Cloudflare 복구 사본에는 이전 암호문이 최대 30일 남을 수 있습니다. 사이트 데이터를 지우기 전에 연결을 먼저 해제해 주세요. 한 Garmin 계정은 한 브라우저에 연결하며 기기 간 복구는 제공하지 않습니다.

AI 처리 동의: 자동 연결로 받은 Garmin 데이터를 AI에 보낼 때마다 별도 체크박스로 동의합니다. 선택한 AI에 운동 요약·회복 지표·목표·대화를 전송합니다. 모델 학습·평가·개선에 사용하는 것은 금지하며, 해당 용도를 제외하는 API 상품과 설정을 확인해야 합니다. Google 무료 API와 자발적 모델 개선 데이터 공유는 사용하지 마세요. 동의 체크 해제·추가 요청 중단·AI 키 연결 해제로 향후 전송을 철회할 수 있습니다. 이미 보낸 정보의 삭제는 해당 AI 제공자에 요청해야 합니다. 목표와 계획은 서버에 보관하지 않으며, 훈련 전송은 이번 연결 기능에 포함되지 않습니다.

3. Data in the local prototype

When you choose to connect Garmin, the prototype uses your Garmin Personal API key to request available activity and recovery information. Data may include activity identifiers and names, dates, sport, distance, duration, pace, heart rate, elevation, laps, training-effect values, sleep duration, HRV, and resting heart rate. Activity FIT files may be processed in memory to produce detailed chart samples. The sample parser does not retain original FIT files or route coordinates.

You may also enter a display name, time zone, availability, race or fitness goals, dates, target times, notes, and structured training drafts. Connection and sync status, job results, and the most recent MCP client name and call time are stored for operation and troubleshooting. The application uses this information to display records and charts, provide goal and training context, validate and store workout drafts, and report connection status.

4. Local storage and security

The current prototype stores application records in a SQLite database on the computer where you run it, in the configured data directory (by default .data/). The Garmin API key is encrypted; the encryption key is stored on the same computer. Short-lived Garmin tokens are cached locally with restricted file permissions. The activity database itself is not encrypted by PaceLoop. Protect the computer, its user account and backups accordingly.

The prototype is designed for local use. This public GitHub Pages site does not host that database, receive Garmin records, or provide a cloud backup. Publishing the informational website does not publish your local data.

5. External AI assistants and MCP

Connecting an external AI assistant gives that client access to the PaceLoop tools exposed through MCP. Depending on the tools the client invokes, records, recovery metrics, goals and workout plans can be included in tool responses and transmitted to the selected AI service. Connect only clients you trust and review their permissions and data controls. The local web interface can also request recommendations using configured provider connections. Its API keys are encrypted locally. The public browser workspace supports API keys as described below.

AI services include OpenAI, Anthropic and Google Gemini; actual availability depends on the client you configure. Their handling, retention, processing locations and model-improvement use depend on the product, account settings and terms you choose. PaceLoop does not control or guarantee those providers’ practices. Disconnecting PaceLoop does not delete copies already sent to an AI service. Review the relevant provider policy before sharing health or fitness information. PaceLoop does not itself train AI models on your Garmin records or sell them for advertising.

6. Other service providers and contact messages

Garmin processes requests made to its API under its own terms and privacy policy. GitHub hosts this informational website and source code. Neither GitHub Pages nor the source repository is used by PaceLoop to store local Garmin records.

If you email support.ducklab@gmail.com, your email address, message and attachments are processed through Google Gmail to answer and manage your request. Send only what is needed; do not send API keys, access tokens or complete health-data exports. These providers may process information outside your country under their own policies. See Garmin privacy and Google privacy.

7. Retention, deletion and your choices

Local records remain until you delete them; there is no automatic retention expiry. Disconnecting Garmin removes the stored Garmin connection and cached activity, detail, recovery and sample records from the application, and clears its associated token cache. It preserves your profile, goals and saved workout drafts. Drafts can be deleted separately. Job history and other local settings may remain.

To remove all local application data, stop the web and MCP servers and delete your configured PaceLoop data directory and any backups or exported copies you control. Normal database deletion does not promise forensic erasure. Revoke your Personal API key in Garmin Connect if you want to prevent further access with that key. Remove the MCP connection in your AI client to stop that client’s access.

Support correspondence is kept while needed to resolve and follow up on your request, or meet applicable obligations. Contact us to request access, correction or deletion of information you have sent us. We cannot remotely access or delete your local database, or erase records held independently by Garmin, GitHub, Google or your AI provider; those requests must also be directed to the relevant provider.

8. Future services and policy changes

Garmin automatic connection is being introduced as described above. Workout publication and mobile apps remain planned. Before introducing materially different collection, cloud storage or providers, we will update this policy and provide any notices and choices required for those features. The effective date below identifies this version. Questions and privacy requests may be sent to support.ducklab@gmail.com.

Garmin 개인 API 키(개인 테스트용): 본인 키로 최근 91일 운동과 제공 가능한 수면·HRV·안정 시 심박수를 조회합니다. ‘이 브라우저에 키 기억하기’를 선택하면 동기화 성공 후 키를 AES-GCM으로 암호화해 IndexedDB에 저장하고 다음 접속에 재사용합니다. 내보낼 수 없는 해독용 키도 같은 브라우저에 저장하므로, 같은 프로필에 접근하는 사용자나 사이트 스크립트는 연결을 사용할 수 있습니다. 옵션을 끄면 현재 탭 메모리에서만 사용합니다. 키는 백업 파일에서 제외합니다. 키·인증 토큰·응답은 Cloudflare 중계의 요청 메모리에서 일시 처리되며 서버에 저장하거나 로그에 남기지 않습니다. 허용한 Garmin 읽기 전용 주소만 호출합니다. 상세 그래프용 FIT 원본도 중계 메모리를 거쳐 브라우저에서 해석하며 원본 파일·GPS 좌표는 보관하지 않습니다. 필요한 측정값과 계정을 구분하기 위한 단방향 식별자는 브라우저에 저장합니다. 개인 키 연결 해제는 메모리와 브라우저 저장소의 키를 제거하고 가져온 기록은 유지합니다. 키 자체의 폐기는 Garmin Connect에서 진행합니다. 여러 사용자를 대상으로 하는 상용 연동의 승인을 의미하지 않습니다.

AI 요청: 기억하기를 선택한 API 키는 AES-GCM으로 암호화해 이 브라우저의 IndexedDB에 보관하고 재사용합니다. 내보낼 수 없는 복호화용 키도 같은 브라우저에 보관하므로 같은 프로필에 접근하는 사람이나 스크립트의 사용까지 막지는 못합니다. 선택하지 않으면 현재 탭 메모리에서만 사용합니다. 키는 백업에서 제외하며, 키 삭제는 로컬 연결만 해제하고 제공자의 키를 폐기하지는 않습니다. 키 확인 시 모델 목록을 조회하고, 추천을 요청하면 최근 운동 요약·목표·대화와 키를 Cloudflare 중계를 거쳐 선택한 OpenAI·Anthropic·Google API에 전달합니다. 중계 서버는 본문·키·응답을 저장하거나 기록하지 않으며, FIT 원본과 GPS 좌표도 전송하지 않습니다. AI 제공자의 자체 보관·국외 처리 정책은 별도로 적용됩니다. Cloudflare는 호스팅·보안을 위해 기술적 접속 정보를 처리하며 중계의 요청 제한에는 IP 해시를 사용합니다. Garmin 미전달 기록을 위한 암호화된 임시 수신함을 사용하며, 기기 간 계정 동기화는 제공하지 않습니다.

별도의 로컬 Python 프로토타입: 사용자 컴퓨터에서 실행하는 버전은 Garmin 운동·회복 데이터와 직접 입력한 목표·프로필·훈련 초안, 연결·동기화 상태를 그 컴퓨터에 보관합니다. API 키는 암호화하지만 암호화 키도 같은 컴퓨터에 있으며 운동 데이터베이스 자체는 암호화하지 않습니다. FIT 파일은 상세 그래프 생성에 처리될 수 있으나 샘플 파서는 원본 파일과 경로 좌표를 보관하지 않습니다.

외부 AI를 MCP로 연결하면 AI 클라이언트가 호출하는 도구에 따라 기록과 목표 등이 해당 서비스에 전달될 수 있습니다. 제공 업체의 보관·국외 처리·모델 개선 사용 여부는 선택한 제품과 계정 설정에 따릅니다. PaceLoop는 외부 AI가 이미 받은 사본을 삭제하거나 그 처리 방식을 보장하지 않습니다. PaceLoop 자체는 Garmin 기록으로 AI 모델을 학습하거나 광고 목적으로 판매하지 않습니다.
